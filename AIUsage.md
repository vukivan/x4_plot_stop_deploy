## AI Usage in this mod

AI was NOT used for:
- generating xml diff files in libraries and md (see exceptions below)
- editing vanilla files from which diffs were generated
- content.xml
- text files
- this file

Edits to vanilla files were done manually.

AI was used for:
- anaylsis of vanilla code
- troubleshooting
- filling in full file paths when invoking diff scripts because who has the time
- readme file

Exceptions:
- icons.xml diff file was AI constructed. script I use can't do it, and I was too lazy.
- Nila Ti character portrait. AI repainted the head of "Fomo Fi" vanilla file. Suit and background was manually edited.
- wares.xml diffs for timelines ships.
