## AI Usage in this mod

### AI was used for:
- anaylsis of vanilla code (most of my kiro tokens go here, over 90%)
- troubleshooting (find the fault, suggest options, minor typo fixes, indentation fixes)
- large operations that don't introduce new code such as migrating vanilla cues (some story cues were moved to setup files)
- filling in full file paths when invoking various diff and deployment scripts, though I do this manually now to save on tokens
- compatibility patch for XUP (stub cues)
- BosoOffer basic cue which replaces vanilla HQ plot. Other cues were either vanilla or written manually.
- icons.xml diff - this is the only diff file that was constructed by AI
- Nila Ti character portrait. AI repainted the head of "Fomo Fi" vanilla file. Suit and background was manually edited back in.
- wares.xml diffs for timelines ships, other diffs were done manually!

### AI was NOT used for:
- generating xml diff files in libraries and md (except icons.xml)
- editing vanilla files from which diffs were generated
- content.xml
- text files
- this file
- bug fixes, other that error codes due to XUP. this was fixed by AI
